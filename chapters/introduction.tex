\section*{The big picture}

This project investigates the energy cost of neural network inference on edge devices (such as the Raspberry~Pi~5 and NVIDIA Jetson platforms) and uses physical measurements to guide hardware-aware Neural Architecture Search (NAS). The workflow connects three specialized tools:

\begin{itemize}
    \item \textbf{JouleQuest (Measurement)}: Runs automated campaigns on target hardware and records power traces with an INA226 sensor, producing clean, structured CSV and JSON datasets with a single command.
    \item \textbf{JouleGrad (Estimation)}: Converts empirical layer profiles into differentiable, multilinear energy surrogates, enabling PyTorch optimizers to penalize energy directly during training.
    \item \textbf{JouleNAS (Search)}: Prunes convolutional channels on frozen backbones to discover architectures that balance classification accuracy against real hardware energy.
\end{itemize}

A dedicated synthesis chapter (Chapter~4: The Bridge) connects the pipeline: profile with JouleQuest, compile the lookup table, estimate with JouleGrad, search with JouleNAS, and test the pruned ResNet-18 model back on physical silicon.

\section*{How to read this document}

Each chapter is modular and self-contained, allowing you to jump directly to the tool you need. If you are collecting new measurements, start with Chapter~1 (JouleQuest), which covers wiring, software setup, dry runs, and campaign orchestration.

A quick note of caution: embedded setups are sensitive to voltage drops, thermal build-up, and cable quirks. If an experiment fails, check the physical wiring, power supply ratings, and SSH authentication first. Configuration issues are far more common than software bugs.
